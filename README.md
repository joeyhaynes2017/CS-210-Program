# CS-210-Program

Description:
The purpose of this project is to take a file that was provided and create outputs based on the data. This program also prompts the user to select an option through the list the program offers. When selecting the option, it will allow the user to specify a product to look for and return the product sold (if any) and display a hictogram of all products and how many were sold.

What was done well:
For me, creating the outputs for the user worked really well, as well as the prompts for the user to enter when looking up an item they were needing. 

Improvements:
I could probably use some improving on formatting and having less errors occur when doing so.

Most challenging:
This would definitely be creating a histogram. It involved string formatting in C++ to get the information the user is wanting to obtain from a file. I overcame this by referring to my zyBooks lessons and labs to make sure my code was using the right functions. 

Transferrable Skills:
The best takeaway I took from this project would be handling input streams. In my opinion, most work that's involved in this field will definitely involve a concept like this to work with.

Code Maintenance:
Maintenance consumes around 60% of the total budget of a program/software. It's very important to properly maintain the program and make sure that you are following a routine of making updates of the program.
